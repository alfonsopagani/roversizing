# Registro delle modifiche

Ogni modifica allo strumento va registrata qui, dalla più recente alla più vecchia. I gruppi che modificano o estendono un modello aggiungono una voce con lo schema seguente e la presentano alla review insieme ai risultati.

## Schema di una voce

```
## [versione] - data - missione del gruppo
- File e funzioni modificati:
- Che cosa cambia (equazione prima e dopo):
- Motivazione e fonte (requisito, sezione della Scheda, documento citato, ipotesi):
- Nuove chiavi del file di input:
- Test aggiunti:
- Effetto sui risultati: massa totale e grandezze principali del proprio rover,
  con la versione originale e con quella modificata, a parità di file di input.
```
